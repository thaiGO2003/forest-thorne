## v5 preview/action convention + v4 audit corrections

- Species/anatomy classification now keys primarily from **unit IDs**, eliminating substring collisions such as `ong` matching Rồng/Phong/Khổng.
- All five boss skills use their dedicated boss authority files.
- `roc_legend`, `triceratops_charge`, `deer_song`, `whale_song`, `ice_mage`, `worm_ice`, `cat_goldbow` and other legacy-name exceptions have explicit anatomy mappings.
- Hit-Impact prioritizes the primary skill name/effect; mixed utility skills may receive a custom combined impact specification.
- No row may contain generic `Kỹ năng riêng` or generic anatomy fallback.

## Global production rules

1. **Visible cubic first:** ~4× authored cubic density via raised/layered micro-voxels; invisible same-color subdivision does not count.
2. **Stable gameplay footprint:** no scale inflation, gameplay-root X/Z animation or facing drift.
3. **Named articulated anatomy:** every anatomy/prop referenced below must exist as named nodes.
4. **Five visible Library states:** `idle` (VI: **Rảnh rỗi**) / `attack` (**Đánh**) / `skill` (**Kỹ năng**) / `take-hit` (**Chịu đòn**) / `move` (**Di chuyển**). Every non-idle Library action loop is exactly **5 seconds**. `combat-idle` is retired. `hit-impact` is internal contact FX only and must not appear as a Library action button.
5. **Attack ≠ Skill:** different silhouette, anticipation, timing and FX.
6. **Skin ownership:** every authored skin stays QA-selectable and resolves its own provenance/evolution.
7. **Reset safety:** all temporary projectile/debris/ring/aura/Zz/sigil/web/flame/splash meshes reset deterministically.
8. **Shared runtime generic only:** unit pose math stays under `src/three/animals/<unit>/`.
9. **Rear/hind gait gate:** any four-legged Move animation must visibly animate at least one rear/hind limb as well as the front pair; use diagonal gait where anatomy allows, and give rear limbs visible lift/rotation rather than front-only motion.
10. **Full-body composition ownership:** every production unit composes its complete anatomy inside its own `src/three/animals/<unit>/Three*Rig.ts`. Shared utilities may build reusable parts only (tail segments, limbs, eyes, wings, horns, micro-voxel pieces, FX). Production must not use `createConfiguredBespokeRig` or `createGeneratedUnitGeometry` to synthesize a whole animal. Until migrated, a unit uses a neutral non-animal migration marker.

## Legacy whole-animal wrapper quarantine

- Initial audit found a large legacy wrapper backlog around `createConfiguredBespokeRig(...)`. Exact raw wrapper count is informational only; the canonical production gate is now **unit-owned registry membership + source-level prohibition on whole-animal composers**. Legacy wrappers do **not count as bespoke/source-complete production visuals**.
- `ThreeUnitModelFactory` must never import or call `createConfiguredBespokeRig` or `createGeneratedUnitGeometry`.
- Only entries in the direct unit-owned path / `ThreeUnitOwnedRigRegistry` may provide complete anatomy to production.
- Unfinished units render the neutral `ThreeUnfinishedUnitVisual` marker; they must never impersonate a guessed species/family.
- Example regression: `wasp_assassin` must not render a quadruped/dog-like body while its own wasp rig is pending.
- A migrated unit is accepted only when its own `Three*Rig.ts` composes the full silhouette and shared imports are part/primitives only.
